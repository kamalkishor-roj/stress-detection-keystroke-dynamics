# Stress Detection Using Natural Keystroke Dynamics

This is a final-year Computer Engineering project that analyzes natural typing behavior to detect stress using keystroke dynamics.

## Features
- Privacy-safe keystroke capture (no text recorded)
- Two-task design (easy vs difficult)
- Client-side feature extraction
- Server-side CSV dataset storage
- No authentication or personal data

## Tech Stack
- HTML, CSS, JavaScript
- Node.js, Express
- CSV-based dataset storage

## How to Run
```bash
cd server
npm install
node server.js
